# 阅读成果持久化与上下文整理验收

## 范围与归属

用户授权实现两项：可持久化阅读笔记、围绕成果的上下文整理。不包含扫描页OCR，不迁移Agent底座。用户在实施中提出底座替代方案问题，因此保留已验证的代码，不在本轮替换SDK或重启本地服务。

已存在的边界决定：Forge管理Work及轨迹，CertLab管理业务状态和专业授权。实现从领域笔记校验/分页开始，通过AgentRunnerPort和ForgeUseCases.startTurn复用TrajectoryPort，最后由Pi适配器暴露工具和投影。来源身份来自真实观察，笔记是Agent的易错观察。旧业务记录、原始文件、OM和既有轨迹均未修改。

修改闭包：`reading-notes.ts`和领域测试、AgentRunnerPort、startTurn、Pi工具适配器、预算投影、摘要提示及缓存版本、上下文/SDK/用例回归、契约和行为场景。没有新增HTTP端点、数据库表或前端流程。
