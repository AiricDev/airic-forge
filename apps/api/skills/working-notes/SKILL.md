# Working notes for continuing a task

Use native working files when the task has several evidence-gathering steps, unresolved details, or must continue later. Keep a small artifact after a coherent set of findings; choose useful task granularity rather than writing after every tool call. On resume or compaction, inspect existing notes before repeating completed investigation.

A useful handoff preserves:
- Current goal, scope and the fixed identity/version of each relevant source.
- Findings and their exact source positions. Preserve task criteria and contextual references as well as retrieved observations; both remain sources in notes and deliverables. A factual citation alone does not establish a criterion. Separate observations from interpretations and user statements.
- What was actually inspected: text ranges, received visual views/regions, unresolved details and uninspected coverage. Returning metadata about an image does not mean receiving its pixels; receiving pixels does not guarantee correct interpretation.
- Completed outcomes, original committed receipts, unresolved command identities and unsaved work.
- The next useful step and any dependency on new information or human decisions.

Use the source App's tools and their current descriptions for searching and reading its materials. Do not access an App-managed original through host files or install a parser as a substitute. Notes are fallible observations, not authoritative source data, current business state, permissions or professional acceptance.

Reopen originals for a specific unresolved detail, contradiction, source change or missing coverage. Do not restart all reading because an older view left active context. Never turn an incomplete inspection into an absence claim or a previous draft into proof. Keep short necessary findings; do not copy raw documents, credentials, images or private reasoning into notes or OM.

Business effects still use the App's authorized tools. Retain the original receipt and command identity; an unknown outcome is not permission to repeat the effect. Formal candidate changes still use the existing governance tools.
