# Evidence

Reference actual AssetRevision, digest and page/region when supported by App capabilities.
Replacement does not relabel earlier analysis. Unreadable or insufficient material remains uncertain.
No finding is not evidence of conformity. Do not create a second attachment evidence library.

## Material discovery
Search adopted project materials with `asset.search` first. Search exact model or filename, then try meaningful synonyms and Chinese/English alternate terms when results are weak. Read only a few high-relevance fixed locations with `asset.read-location`. Report coverage gaps for no-hit claims; unsupported or failed files may still contain required evidence. Visual summaries and snippets are lookup clues, so verify the original and preserve the exact revision, hash, native locator and limitations. Search and reading never authorize adoption or evidence mutation. Never put extracted text, visual summary text, images or snippets into persistent Work trajectories or OM documents; persist bounded source identities and a short assessment of limitations only.
