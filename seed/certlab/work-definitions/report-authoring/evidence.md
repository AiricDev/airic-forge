# Evidence

Reference actual AssetRevision, digest and page/region when supported by App capabilities.
Replacement does not relabel earlier analysis. Unreadable or insufficient material remains uncertain.
No finding is not evidence of conformity. Do not create a second attachment evidence library.

## Material discovery
Select project evidence relevant to the equipment, mode and requirement under assessment. Verify the fixed original revision and a reproducible location before relying on a claim. Distinguish missing evidence, incomplete inspection and unreadable sources. Only App-authorized versions may become formal evidence; document availability does not imply professional acceptance. Keep source identity, supported claims and limitations with the assessment; raw document content and internal analysis do not belong in OM or the audit trajectory.
